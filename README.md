# 麦麦批准 McApproved

> 说一件今天发生的事，麦当劳给你盖章批一顿。

**👉 [在线试玩（手机打开更好玩）](https://pakco77.github.io/mctrack/app/)**　·　觉得好玩，右上角点个 ⭐ Star

## 为什么做这个

人想吃麦当劳，多半不是因为饿，是想给今天一个交代：加班到十点、被甲方改了第八版、终于发工资了。缺的只是一个理由，和一点不心疼。

麦麦批准把这件事做完整：**说中你的今天 → 盖章批准 → 券后价算好 → 想吃就一键下单**。

## 玩法

1. 打开就是一张「犒劳申请单」：先按此刻时间跟你打个招呼（凌晨：还醒着的人，今天一定不容易）
2. 填申请事由（8 个常见事件，或者自己写一句）和想吃点（汉堡/炸鸡/辣的/甜的/清淡点/都行）
3. 提交 → 审批意见逐字打出 → 大红章「咚」地砸下 → 批准的食物从「?」里蹦出来，变成白边贴纸
4. 运气好会拿到**金章特批**（约 1/6，同一天同一事由结果固定，刷新刷不出来）
5. 不爱吃就「换一个」，份量档位不变；领券去吃，或截图批准书发群

## 匹配规则：犒劳指数定份量，口味定吃什么

犒劳指数 1～4 星，对应约 93～774 kcal：发生的事越辛苦，批得越多；最低档「啥也没干」只批一份小的。
口味决定吃什么：选「辣的」就在辣的里挑，选「清淡点」就给板烧和麦香鱼。WorkBuddy 版还会查你的历史订单，优先批你真正常点的。

犒劳讲刚好，不是越惨吃越多。每张批准书都标热量，数据来自麦当劳 MCP 营养接口。

## 安装

### 方式一：WorkBuddy Skill（完整体验：真实菜单、真领券、真下单）

1. 申请麦当劳 MCP Token：[open.mcd.cn/mcp](https://open.mcd.cn/mcp)（手机号登录 → 控制台 → 激活）
2. WorkBuddy 左侧边栏【专家·技能·连接器】→【连接器】→【自定义连接器】→【配置MCP】，粘贴 `mcp-config.example.json` 内容并替换 `YOUR_MCP_TOKEN`
3. 将本仓库 `SKILL.md` + `app/` 安装为 WorkBuddy 技能，启用 mcd-mcp 连接器
4. 对 WorkBuddy 说：「批我一顿，今天被甲方改了第八版」

### 方式二：纯 H5（无需 Token）

打开 [在线试玩](https://pakco77.github.io/mctrack/app/)，或直接打开本地 `app/index.html`。使用内置菜单快照，价格为门店价，不领券。

## 使用示例

- 「批我一顿，今天被甲方改了第八版」→ 被骂了 ★★★★ → 双层吉士汉堡 + 新地，标券后价
- 「跑了 10 公里」→ 运动打卡 → 板烧鸡腿堡 + 苹果汁
- 「啥也没干，就是馋」→ 只批一个甜筒
- 「就吃这个」→ 复述门店、餐品、金额，确认后调 `create-order` 下单

## 目标用户

- 打工人和学生：需要一个理由犒劳自己，又怕花多、吃多
- 选择困难的麦当劳常客：不想翻菜单，要一个"刚好"的答案
- 想用 MCP 做情绪类场景的开发者（本仓库即参考实现）


## 技术说明

- **单文件 H5，零依赖**：审批悬念、印章砸下、放射光、彩纸、烟花全部纯 CSS；食物白边贴纸用 CSS 多层投影沿透明抠图描边；音效用 Web Audio 合成，无音频文件
- **真实数据**：菜单与价格来自 MCP `query-meals`（东莞门店快照），热量来自 `list-nutrition-foods`，图片走麦当劳官方 CDN
- **兜底**：菜单图加载卡住 2.5 秒自动换插画；MCP 不可用时用快照并标「门店价」
- **隐私**：Token 只存本机 MCP 配置，不进入仓库与页面；用户的一句话只在本机页面显示，不上传
