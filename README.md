# 麦乐点唱机 McTrack

> 拍张自拍，读懂你此刻的情绪 —— 让歌和饭发生一场化学反应。

**今日麦麦主题曲**：自拍 → 情绪关键词 → 匹配主题曲 → 匹配今日主餐 → 领取优惠券 → 生成分享卡片 → 一键下单。

## 这是什么

一个基于[麦当劳中国 MCP](https://github.com/M-China/mcd-mcp-server) 的 WorkBuddy Skill：把「此刻情绪」当催化剂，让音乐 × 餐品碰出第三种产物——**今日最搭**：一首本地实时合成的主题曲 + 一款来自真实菜单的主餐 + 算好优惠券的最省点法，最后产出一张可以截图发群的分享卡片，并可在 WorkBuddy 里一句话下单。

## 玩法

1. 在 WorkBuddy 里发一张自拍（或说一个情绪：加班到崩溃 / 今天想嗨 / 有点 emo……）
2. McTrack 判定你的「音乐人格」，从麦当劳 MCP 拉取真实在售菜单匹配今日主餐
3. 自动 `auto-bind-coupons` 领券 + `calculate-price` 算最省价
4. 生成你的专属点唱页：主题曲片段（Web Audio 实时合成，非录音零版权问题）+ 主餐 + 匹配度 + 最省点法
5. 截图卡片去群里炸场；想吃就说「就点这个」，一键下单

## 安装

### 方式一：WorkBuddy Skill（完整体验）

1. 申请麦当劳 MCP Token：[open.mcd.cn/mcp](https://open.mcd.cn/mcp)（手机号登录 → 控制台 → 激活）
2. WorkBuddy 左侧边栏【专家·技能·连接器】→【连接器】→【自定义连接器】→【配置MCP】，粘贴 `mcp-config.example.json` 内容并替换 `YOUR_MCP_TOKEN`
3. 将本仓库 `SKILL.md` + `app/` 安装为 WorkBuddy 技能，启用 mcd-mcp 连接器
4. 对 WorkBuddy 说：「麦麦主题曲」或发一张自拍

### 方式二：纯 H5 体验（无需 Token）

直接双击打开 `app/index.html`（手机/电脑浏览器均可）。此时使用内置示例数据，接入 MCP 后自动切换为真实菜单与券价。

## 使用示例

- 「麦麦主题曲」→ 按当前时间推断场景自动点唱
- 「加班到崩溃，给我配一首」→ 深夜 Lo-Fi × 麦辣鸡腿汉堡 + 热美式
- 「在听晴天」→ 歌曲名进主题曲，生成《晴天 × 麦麦》
- 「就点这个」→ 复述门店/餐品/金额，确认后调 `create-order` 下单

## 目标用户

- 点单前选择困难的麦当劳常客
- 喜欢「测测今日运势」式轻互动、愿意截图分享的年轻用户
- 想用 MCP 做点有趣东西的开发者（本仓库即参考实现）

## 项目结构

```

```

## 技术说明

- **主题曲引擎**：Web Audio API 实时合成（底鼓/镲/贝斯/和弦垫/黑胶噪声），按情绪配置 BPM、调式、摇摆度，无任何音频文件与版权风险
- **匹配度**：同一天同一情绪输出恒定结果（日期哈希），可复现、可分享对答案
- **兜底策略**：MCP 不可用时 H5 使用内置示例数据并明确标注，不中断体验
- **隐私**：Token 只存本机 MCP 配置，不进入仓库与生成页面；自拍仅在本机页面展示，不上传
